# Security Policy

## Reporting a vulnerability

Do not open a public issue for vulnerabilities or suspected privacy leaks. Use
GitHub's private vulnerability reporting for this repository. Include affected
versions, reproduction steps, impact, and any suggested mitigation.

Do not include real credentials, captured MCP payloads, fingerprint salts, or
other sensitive data in a report. Use synthetic examples whenever possible.

## Supported versions

Until the project reaches 1.0, security fixes are applied to the latest release
and the `main` branch.
